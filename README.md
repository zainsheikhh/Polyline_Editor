In the Polyline Editor project, my role was to perform task analysis, which means I focused on understanding how users interact with the system step by step. I identified the main tasks such as drawing a polyline, editing points, moving shapes, and deleting them. Then, I broke each task into simple actions like selecting tools, clicking on the canvas, and dragging points. I also analyzed possible problems users might face, such as confusion in completing a drawing or difficulty selecting points. Based on this analysis, I suggested improvements like adding undo/redo options and better visual feedback. My work helped in making the system more user-friendly and easier to understand.
